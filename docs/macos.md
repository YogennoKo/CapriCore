# Capri на macOS

Из Терминала выполните команды ниже. Для первого запуска нужны Git, Node.js с npm и интернет.

```sh
git clone --branch macos https://github.com/YogennoKo/CapriCore.git
cd CapriCore
./scripts/macos.sh --chatgpt
```

Скрипт устанавливает версии Node.js и npm для этой сборки в каталог проекта. Electron загружается для архитектуры вашего Mac. Для повседневного запуска используйте `./scripts/macos.sh`. При уже запущенном Capri настройки доступны через меню приложения.

В **Settings → API connections → Connect your ChatGPT plan** нажмите **Continue with ChatGPT**. В браузере войдите в нужный аккаунт и подтвердите использование плана. Выберите модель из списка своего аккаунта, нажмите **Test connection**, затем **Use connection**. При выборе режима инференса можно пропустить запуск локальной языковой модели. Доступ к моделям и ограничения определяются аккаунтом. Capri хранит регистрацию отдельно, используя шифрование Electron с системной связкой ключей macOS. [Вход через ChatGPT](https://developers.openai.com/siwc/quickstart/)

## Экран, управление и звук

Для полного набора описанных ниже возможностей нужны macOS 14.2 или новее и инструменты разработчика Apple (`xcode-select --install`). При первом запуске скрипт собирает нативный модуль из исходников. Команда `./scripts/macos.sh --permissions` запрашивает разрешения на запись экрана и Универсальный доступ и выводит их состояние.

- **Экран.** Выберите окно или монитор в Capri. Снимки мониторов и областей обрабатываются через ScreenCaptureKit. В «Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного аудио» разрешите запись процессу, который укажет macOS. При запуске из Терминала разрешение может потребоваться Терминалу. После изменения разрешения перезапустите Capri.
- **Управление приложениями.** Включите доступ к нужному приложению в Capri. Для управления активным окном разрешите «Универсальный доступ» в настройках macOS. Поиск и запуск работают с пакетами .app. Управление использует элементы Accessibility, ввод в доступные текстовые поля, клики, прокрутку, простое перетаскивание и сочетания клавиш. Комбинации с CTRL в командах Capri соответствуют Command на Mac. Escape останавливает сеанс. Сначала попробуйте ввод в пустом окне TextEdit.
- **Звук звонков.** Установите [BlackHole 2ch](https://existential.audio/blackhole/) или выполните `brew install --cask blackhole-2ch`. В Capri выберите физический микрофон и нажмите **Settings → Voice calls → Set up automatically**. В приложении звонка выберите **BlackHole 2ch** как микрофон и обычные наушники как выход. Capri направит в BlackHole голос и выбранный микрофон. Для распознавания музыки один раз запустите `./scripts/macos-music.sh` (Python 3.12 или 3.13). При первом включении Capri загрузит проверенную по хешу модель YAMNet. Для прослушивания музыки и системного звука используйте системный источник по умолчанию. Для системного звука Capri запускает аудиопоток ScreenCaptureKit и останавливает его при завершении сеанса.
- **Границы порта.** Специализированные действия Steam, шахмат в браузере, Discord и Resolve, виртуальная камера Windows, запись с отдельных WASAPI-устройств и установщик Windows не портированы. Для доступа к элементам окна приложение должно предоставлять соответствующие элементы Accessibility.

Обновляйте ветку командой `git pull --ff-only` и снова запустите скрипт.
